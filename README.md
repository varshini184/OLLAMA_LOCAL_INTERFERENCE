# Week 8: Local LLM Inference Using Ollama

## Project Overview

This project demonstrates local Large Language Model (LLM) inference using Ollama and the Llama 3.2 model. It processes prompts from a CSV dataset, stores model responses in a CSV file, and provides an interactive chat interface using Streamlit.

## Technologies Used

* Python
* Ollama
* Llama 3.2
* Streamlit
* Pandas

## Project Structure

```text
ollama_local_inference/
├── Dataset/
│   ├── prompts.csv
│   ├── llm_responses.csv
│   ├── response_comparison.csv
│   └── conversation_history.txt
├── app.py
├── ollama_local.py
├── compare_responses.py
├── requirements.txt
└── README.md
```

## Setup

1. Install Python.
2. Install Ollama and download the model:
   `ollama pull llama3.2`
3. Install Python dependencies:
   `python -m pip install -r requirements.txt`

## Run the Project

### Batch Inference

Run the Python script to process prompts from the dataset and save the model responses:
`python ollama_local.py`

### Interactive Chat

Start the Streamlit interface:
`streamlit run app.py`

### Prepare Response Comparison

Generate the response comparison CSV:
`python compare_responses.py`

## Evaluation

The model responses can be reviewed for quality, accuracy, and relevance. Add observations based on the actual responses generated by the model.

## Conclusion

This project demonstrates how a local language model can generate responses to prompts without relying on a hosted LLM inference API.
